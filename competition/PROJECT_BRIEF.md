# ini-mbt 参赛项目说明

## 推荐赛道

MoonBit 生态基础库 / 开发工具库。

## 项目定位

`ini-mbt` 是一个面向 MoonBit 的 INI 配置文件解析器，提供轻量、可测试、可复用的配置读取能力。

INI 是大量命令行工具、游戏配置、桌面软件和嵌入式项目仍在使用的简单配置格式。MoonBit 生态中补齐一个小而可靠的 INI 解析库，适合作为第一个参赛项目跑通完整流程。

## 为什么适合作为第一个项目

- 功能边界清晰：按行解析 section、key-value、注释和空行。
- 实现难度适中：不需要复杂依赖，也不需要大规模架构。
- 验收友好：可以通过示例、单元测试和 README 快速证明项目可用。
- 可扩展空间明确：后续可以加入错误定位、序列化、类型转换和格式化输出。

## MVP 功能

- 解析 `[section]` 分区。
- 解析 `key = value` 和 `key: value`。
- 支持 `;` 和 `#` 注释。
- 支持空行。
- 支持全局配置项。
- 提供 `get(section, key)` 查询。
- 提供 `get_or(section, key, default)` 查询。
- 提供基础测试用例和 README 示例。

## 非 MVP 功能

这些功能先不进入第一轮，避免项目膨胀：

- 多行 value。
- 插值变量。
- 写回 INI 文件。
- 自动类型转换。
- 保留原始注释和格式。
- 与 Python `configparser` 完全兼容。

## 验收目标

- 仓库可以通过 `moon check`。
- 测试可以通过 `moon test`。
- README 包含安装、使用示例、API 说明和限制说明。
- 至少 20 个真实 commit，每个 commit 都对应一个可解释的开发动作。
- 最终项目能作为 MoonBit 配置解析基础库独立使用。
